# BookEase — live demo

Online appointment booking for salons, clinics, tutors and other service businesses.

- Salon demo: `index.html?business=salon`
- Dental clinic demo: `index.html?business=clinic`
- Tuition centre demo: `index.html?business=tuition`
- Owner dashboard: `admin.html` (demo PIN 1234)

This is a demo build. Bookings are saved only in your browser.
